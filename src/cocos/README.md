# Cocos demos

| Cocos Creator | Project | Entry scene |
| --- | --- | --- |
| 3.8.8 | [demo](demo/README.md) | `demo/assets/scenes/Demo.scene` |
| 2.4.9 | [demo-2.4.9](demo-2.4.9/README.md) | `demo-2.4.9/assets/scenes/Demo.fire` |

Both editions provide Crystal Dash, native lobby/results/settings, the SDK lab and Session Replay experiments with the same layout. Open each project with its matching Creator version and run `npm run setup` inside that directory before building.

The SDK lab includes **Full component coverage** migrated from the SDK Hybrid samples: 11 entries for Creator 2.4.9 and 17 for Creator 3.8.8, covering real UI components, 3D and engine-specific diagnostics.
